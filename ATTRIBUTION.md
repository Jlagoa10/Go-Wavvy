# Referências visuais

O redesenho usa padrões de interface encontrados no catálogo 21st.dev: ondas suaves no fundo, gradientes, brilho nos botões e luz no hover dos cartões.

- https://21st.dev/@bundui/components/wavy
- https://21st.dev/community/components/s/card
- https://21st.dev/ (demonstração Shimmer Button)

A implementação em HTML, CSS e Canvas foi escrita para este projeto. Não foi instalado um pacote do 21st.dev nem copiado um componente premium.

Os três jogos foram adaptados a partir dos arquivos públicos dos endereços fornecidos pelo usuário. A lógica original e a conexão pública existente com Supabase foram preservadas. A logo foi fornecida pelo usuário.

## Ícones

[Lucide](https://lucide.dev/) / lucide-static 1.54.0, licença ISC. SVGs locais em assets/icons; licença original incluída no diretório.
